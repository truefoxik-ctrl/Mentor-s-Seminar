Работа со Spark в кластере Yandex DataProc

Структура репозитория:
-Pdf-файл с демонстрацией корректной работы кода в Zeppelin

-.ipynb - файл c пометкой markdown - файл с кодом в ячейках markdown, т.к. экспорт из Zeppelin не открывается корректно на GitHub

-.ipynb - файл c пометкой from Zeppelin - файл, экспортированный из Zeppelin. Не открывается напрямую на GitHub, но его можно скачать и открыть в VSCode или в UI Zeppelin
